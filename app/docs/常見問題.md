# 常見問題

## 安裝

**雙擊安裝檔後出現「Windows 已保護您的電腦」**
按「其他資訊」→「仍要執行」。檔案從網路下載又沒有數位簽章時，Windows 都會這樣擋一次。

**Mac 說安裝檔無法打開**
見[安裝](安裝.md)的 Mac 那節，改用終端機執行。

**安裝檔說 uv 沒裝成功**
多半是網路被擋（例如公司網路）。換個網路再雙擊一次安裝檔。

**安裝在某一步失敗了**
畫面上會寫是哪一步、最後幾行錯誤訊息，完整記錄在程式資料夾的 `logs\install.log`。修好之後再雙擊一次安裝檔，已經下載好的模型不會重新下載。

**桌面上沒有「會議紀錄」捷徑**
英文語系的 Windows 建不了中文名稱的捷徑，安裝檔會跳過這步並提醒。直接到使用者資料夾打開 `會議紀錄` 就好，也可以自己在檔案總管對它按右鍵「傳送到 → 桌面（建立捷徑）」。

**顯示卡驅動太舊**
安裝檔會先用 CPU 裝好。到 NVIDIA 官網或電腦廠商的網站更新驅動，再跑一次安裝檔就會改用顯示卡。RTX 50 系列要支援 CUDA 12.8 以上的驅動。

## 使用

**輸入 `/會議紀錄` 沒反應，或說找不到這個指令**
要在工作區（`會議紀錄` 資料夾）打開 Claude Code 才叫得出來。在別的資料夾打開是找不到的。

**一直跳權限詢問**
見[使用流程](使用流程.md)的「權限詢問」：選「Yes, and don't ask again」就不會一直問。

**支援哪些錄音格式**
m4a、wav 實際測過。mp3、flac、ogg、mp4、webm 應該可以，沒有逐一測過。

**錄音的時間不對、順序排錯**
程式先看檔名裡的時間（例如 `語音 YYMMDD_HHMMSS`、`YYYYMMDD_HHMMSS`），沒有再看檔案裡記錄的時間，最後才看檔案修改時間。後兩種會標「時間不確定」，Claude 會請你確認。複製過的檔案，修改時間可能變成複製當下。

**人名、專有名詞聽錯**
下次在 Claude 問「有沒有名單或專有名詞」時提供，或在會議資料夾放 `0_名單與術語.txt`，再請 Claude 重轉。名單太長時，後面的會被截掉，Claude 會告訴你哪些沒用上。

**轉逐字稿中途關掉了**
跟 Claude 說「接著轉逐字稿」就好。錄音已經搬進會議資料夾，做完的段落也存起來了，只會轉沒做完的。

**顯示卡轉到一半出錯**
程式會自動改用 CPU 重轉那一段，並告訴你原因。

**會議紀錄的格式想改**
跟 Claude 說要怎麼改就好。要長期改的話，工作區的 `.claude\skills\會議紀錄\` 裡有整理規則和格式公版（Windows 上這個資料夾是隱藏的）；重新安裝或更新時，你改過的整理規則會備份成 `整理規則.舊.md`。
