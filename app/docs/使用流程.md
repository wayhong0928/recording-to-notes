# 使用流程

## 開會前（選用）

工作區最上層有一份 **`會議紀錄範本.md`**，是空白的會議紀錄：開頭是專案名稱、會議名稱、會議地點、會議時間、與會人員、記錄人，接著是會議內容、決議事項、討論事項。

1. 開會前複製一份（例如改名成會議名稱），先填好知道的欄位，在「會議內容」列出議程。
2. 開會時直接記在上面。用記事本、VS Code 都可以，也可以整份貼進 Teams 的會議筆記。
3. 會後跑 `/會議紀錄` 時，Claude 第一題會先問筆記，把這份貼過去或給檔案位置。範本裡填過的欄位會直接用在會議紀錄裡，接下來的問題裡填過的（會議名稱、議程）就不再問；你記的內容會當作筆記，和逐字稿對照後照整理規則重寫。

範本只是給你用的，改它（例如加欄位）不會影響 Claude 寫出來的格式；Word 開頭的欄位是固定的六個，你在範本開頭欄位區多加的欄位（例如「主席：」）不會出現在 Word 裡。

## 每場會議要做的事

1. 把會議錄音放進工作區的 **`錄音放這裡`** 資料夾。一場會議錄成好幾段也沒關係，全部放進去。
2. 在 Claude Code 打開工作區（`會議紀錄` 資料夾）。
   - 終端機版：在工作區資料夾打開終端機，輸入 `claude`。
   - 桌面版：Code 分頁選工作區資料夾。（桌面版還沒實際測過。）
3. 輸入 **`/會議紀錄`**。
4. 回答 Claude 的幾個問題，等它做完，Word 會自動打開。

## Claude 會問什麼

- **是哪幾段錄音**：Claude 會用表格列出錄音的日期、開始時間、長度、和上一段隔多久。錄音依開始時間分組，有好幾組時預設選最新的一組。
  - 同一天的錄音預設算同一場會議。兩段之間空了 1 小時以上，Claude 會問一句是不是同一場。
  - 過了午夜才結束的會議（例如 23:00 開始、隔天 00:30 結束），兩段之間不到 1 小時，算同一場。
- **自己開會時記的筆記或初稿**：可以貼進對話，或給檔案位置；開會前填過的 `會議紀錄範本.md` 也是給這一題，填過的欄位和議程就不再問。只看逐字稿容易抓錯重點，有你的筆記，紀錄會準很多；真的沒有可以跳過。筆記和錄音對不上的地方，以錄音為準，Claude 會在對話裡列出來。
- **會議名稱**：照會議邀請上的名稱（例如 Teams 行事曆上的會議名稱），可以直接複製過來。
- **會議目的或議程**：選填。會議邀請信有列討論事項的話貼過來，Claude 會照議程排會議內容、判斷重點。
- **有沒有與會者名單或專有名詞**：選填。直接打在對話裡就好，逐字稿的人名和術語會比較準。文件代號寫成「代號 = 全名或對應的文件」（例如「xxx = yyy 問卷 Excel」），會議紀錄裡的代號就會附上說明。
- **會議紀錄要存在哪裡**：沒特別說就存在工作區的 `會議` 資料夾。想照專案分開放，就回答那個專案的資料夾（例如 `D:\專案\某客戶\會議紀錄`），錄音也會一起搬過去。

## 轉逐字稿要多久

錄音在你的電腦上轉，不上傳。在開發用的電腦上量到的速度（錄音長度的幾倍）：

| 電腦 | 速度 |
|---|---|
| 有 NVIDIA 顯示卡（RTX 5060 Laptop） | 約 0.07 倍，1 小時的錄音約 4 分鐘 |
| 同一台只用 CPU | 約 0.6 倍，1 小時的錄音約 36 分鐘 |

沒有獨立顯示卡的一般筆電沒測過，可能比錄音本身還久。轉的時候可以先去做別的事。

轉錄時會跳出一個進度視窗，顯示轉到第幾段、百分比、大概還要多久（轉了一分鐘以上、進度超過 5% 才會開始估算）。轉完視窗會自己關掉，中途關掉也不會停止轉錄。想再看進度，直接問 Claude「轉到哪了」，或請它再打開進度視窗。

## 做出來的檔案

每場會議一個資料夾，例如 `會議\2026-10-06_週會\`：

| 檔案 | 內容 |
|---|---|
| `語音 ….m4a` | 原始錄音，從「錄音放這裡」搬過來，檔名不變 |
| `0_會議目的.md` | 你給的會議目的或議程（有給才有） |
| `0_名單與術語.txt` | 你給的名單和術語（有給才有） |
| `0_我的筆記.md` | 你給的筆記或填過的範本（有給才有） |
| `1_逐字稿.md` | 多段錄音合併的逐字稿，時間是實際的時鐘時間 |
| `2_會議紀錄.md` | Claude 整理的會議紀錄，內容以這份為準 |
| `2_會議紀錄_年月日時分秒.docx` | 從上面那份產生的 Word，每次產生一份新檔，舊的不刪 |
| `_暫存\` | 每段錄音的轉錄結果、Claude 寫的第一版原稿，平常不用管 |

會議紀錄的格式是問答式：開頭是專案名稱、會議時間、與會人員這些欄位（會自動填的只有會議名稱和你在範本裡填過的欄位，其他留給你填），接著是會議內容、決議事項、討論事項。Word 裡不放逐字稿的時間，也不加「待確認」這類註記。聽不清楚、看不出是誰說的地方，Claude 會在對話裡逐條列出來給你確認；要找原句可以問 Claude，或打開 `1_逐字稿.md` 看。Claude 也會另外列出「可能沒聽懂的地方」（查不到全名的代號、你的筆記沒記到但討論很多的段落、看不出目的的討論），可以拿去問同事，問到了再請 Claude 改。「下週五前」這類相對的日期，Claude 會照會議日期換成明確日期，換了哪些也會列給你核對。

會議紀錄怎麼寫（決議放什麼、哪些題目要留）照工作區 `.claude\skills\會議紀錄\整理規則.md`，可以改成自己團隊的習慣。

## 要修改會議紀錄

- 直接在對話裡跟 Claude 說要改哪裡，它會改好再產生一份新的 Word。
- 你已經在 Word 裡改過了：把改過的段落複製貼給 Claude。Claude 不會自己讀 Word 的修改，所以沒貼過來的話，新版 Word 不會有那些修改；它發現你改過上一版時會提醒一次。

## 權限詢問

Claude Code 要執行程式或寫檔案之前，會先問你允不允許。`/會議紀錄` 第一次用時會問好幾次：

- 選 **「Yes, and don't ask again …」**（允許，而且這個資料夾以後不用再問），之後就不會再問同樣的事。
- 只選「Yes」也可以，但下次同樣的步驟會再問。

會議紀錄存到工作區以外的地方時，可能會多問幾次。

## 名單和術語怎麼寫

工作區裡的 `術語表範例.txt` 是名單和術語的寫法範例：一行一個，或寫成一段描述。每場會議的名單和術語不一樣，Claude 問的時候直接打在對話裡最快，它會存成會議資料夾裡的 `0_名單與術語.txt`。
