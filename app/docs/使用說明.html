會議紀錄小幫手 使用說明

使用流程 安裝 資料流向 常見問題

使用流程

每場會議要做的事

  1. 把會議錄音放進工作區的 錄音放這裡 資料夾。一場會議錄成好幾段也沒關係，全部放進去。
  2. 在 Claude Code 打開工作區（會議紀錄 資料夾）。
  3. 終端機版：在工作區資料夾打開終端機，輸入 claude。
  4. 桌面版：Code 分頁選工作區資料夾。（桌面版還沒實際測過。）
  5. 輸入 /會議紀錄。
  6. 回答 Claude 的幾個問題，等它做完，Word 會自動打開。

Claude 會問什麼

  • 是哪幾段錄音：Claude 會用表格列出錄音的日期、開始時間、長度、和上一段隔多久。錄音依開始時間分組，有好幾組時預設選最新的一組。
  • 同一天的錄音預設算同一場會議。兩段之間空了 1 小時以上，Claude 會問一句是不是同一場。
  • 過了午夜才結束的會議（例如 23:00 開始、隔天 00:30 結束），兩段之間不到 1 小時，算同一場。
  • 會議名稱。
  • 有沒有與會者名單或專有名詞：選填。直接打在對話裡就好，逐字稿的人名和術語會比較準。
  • 有沒有自己開會時記的筆記或初稿：選填。可以貼進對話，或給檔案位置。筆記和錄音對不上的地方，以錄音為準，Claude 會在對話裡列出來。
  • 會議紀錄要存在哪裡：沒特別說就存在工作區的 會議 資料夾。

轉逐字稿要多久

錄音在你的電腦上轉，不上傳。在開發用的電腦上量到的速度（錄音長度的幾倍）：

電腦 速度
有 NVIDIA 顯示卡（RTX 5060 Laptop） 約 0.07 倍，1 小時的錄音約 4 分鐘
同一台只用 CPU 約 0.6 倍，1 小時的錄音約 36 分鐘

沒有獨立顯示卡的一般筆電沒測過，可能比錄音本身還久。轉的時候可以先去做別的事。

轉錄時會跳出一個進度視窗，顯示轉到第幾段、百分比、大概還要多久（轉了一分鐘以上、進度超過 5% 才會開始估算）。轉完視窗會自己關掉，中途關掉也不會停止轉錄。想再看進度，直接問 Claude「轉到哪了」，或請它再打開進度視窗。

做出來的檔案

每場會議一個資料夾，例如 會議\2026-10-06_週會\：

檔案 內容
語音 ….m4a 原始錄音，從「錄音放這裡」搬過來，檔名不變
0_名單與術語.txt 你給的名單和術語（有給才有）
0_我的筆記.md 你給的筆記（有給才有）
1_逐字稿.md 多段錄音合併的逐字稿，時間是實際的時鐘時間
2_會議紀錄.md Claude 整理的會議紀錄，內容以這份為準
2_會議紀錄_年月日時分秒.docx 從上面那份產生的 Word，每次產生一份新檔，舊的不刪
_暫存\ 每段錄音的轉錄結果、Claude 寫的第一版原稿，平常不用管

會議紀錄的格式是問答式：開頭是專案名稱、會議時間、與會人員這些欄位（只有會議名稱會自動填，其他留給你填），接著是會議內容、決議事項、討論事項。Word 裡不放逐字稿的時間，也不加「待確認」這類註記。聽不清楚、看不出是誰說的地方，Claude 會在對話裡逐條列出來給你確認；要找原句可以問 Claude，或打開 1_逐字稿.md 看。

要修改會議紀錄

  • 直接在對話裡跟 Claude 說要改哪裡，它會改好再產生一份新的 Word。
  • 你已經在 Word 裡改過了：把改過的段落複製貼給 Claude。Claude 不會自己讀 Word 的修改，所以沒貼過來的話，新版 Word 不會有那些修改；它發現你改過上一版時會提醒一次。

權限詢問

Claude Code 要執行程式或寫檔案之前，會先問你允不允許。/會議紀錄 第一次用時會問好幾次：

  • 選 「Yes, and don't ask again …」（允許，而且這個資料夾以後不用再問），之後就不會再問同樣的事。
  • 只選「Yes」也可以，但下次同樣的步驟會再問。

會議紀錄存到工作區以外的地方時，可能會多問幾次。

名單和術語怎麼寫

工作區裡的 術語表範例.txt 是名單和術語的寫法範例：一行一個，或寫成一段描述。每場會議的名單和術語不一樣，Claude 問的時候直接打在對話裡最快，它會存成會議資料夾裡的 0_名單與術語.txt。

安裝

需要準備的

  • Claude Code，用付費方案（Pro 以上）的帳號登入。安裝方式見 Claude Code 官方說明。
  • 硬碟空間約 6 GB：程式和套件約 1 GB，語音辨識模型約 3 GB，有 NVIDIA 顯示卡再加約 1.5 GB。
  • 安裝時要連網路，之後轉逐字稿不用網路。
  • Word（選用）。沒有 Word 一樣會產生 docx，只是不會自動打開。

Windows

  1. 到 GitHub 頁面右邊的 Releases，下載最新版的 recording-to-notes-v版本.zip（Windows 和 Mac 是同一個檔），按右鍵「解壓縮全部」。
  2. 打開解壓縮出來的資料夾，雙擊 安裝（Windows）.bat。
  3. 跳出藍色的「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。這是因為檔案從網路下載、沒有數位簽章。
  4. 視窗會先列出這台電腦的狀況（顯示卡、硬碟空間、網路、有沒有 Word 和 Claude Code），再列出接下來要裝什麼。確認沒問題就按 Enter。
  5. 等它跑完。第一次要下載約 3 GB 的模型，視網路速度要幾分鐘到半小時。最後會用一小段電腦合成的語音試跑一次，看到「安裝完成」就好了。

中途失敗或關掉視窗都沒關係，再雙擊一次安裝檔就好。已經下載好的模型不會重新下載，下載到一半的會接著下載。

有 NVIDIA 顯示卡時會自動裝加速套件，不用另外裝 CUDA。驅動太舊的話，安裝檔會提醒你去更新，這次先用 CPU 裝；更新完再跑一次安裝檔就會改用顯示卡。

Mac

Mac 版照同樣的設計寫好了，但還沒在 Mac 上實際裝過，有問題請回報。

  1. 跟 Windows 一樣到 Releases 下載 ZIP，雙擊解壓縮。
  2. 雙擊 安裝（Mac）.command。
  3. 被擋下來說「無法打開」：打開「終端機」，輸入 bash （後面有空格），把 安裝（Mac）.command 拖進終端機視窗，按 Enter。
  4. 之後跟 Windows 一樣：看檢查結果、按 Enter、等它跑完。

Mac 一律用 CPU 轉逐字稿。Apple Silicon 的 Mac 可能要 macOS 14 以上，因為讀錄音的套件只提供 macOS 14 以上的現成版本（沒實測）。

裝了什麼、放在哪

東西 Windows Mac
程式、Python 環境、模型、安裝記錄 %LOCALAPPDATA%\MeetingMinutes\ ~/Library/Application Support/MeetingMinutes/
工作區（錄音和會議紀錄都在這裡） C:\Users\<你的名稱>\會議紀錄\ ~/會議紀錄/
桌面捷徑 「會議紀錄」，打開工作區 同左

安裝檔還會在使用者資料夾裝一個叫 uv 的小工具（用來裝 Python 套件），不會動到你電腦原本的 Python。

安裝記錄在程式資料夾的 logs\install.log，出問題時可以看這份。

更新

下載新版的 ZIP，再雙擊一次安裝檔。程式會換成新版，模型和工作區裡的錄音、會議紀錄都不動。

工作區裡的 /會議紀錄 設定也會換成新版。你改過整理規則（整理規則.md、問答式.md）的話，舊的會先備份成 整理規則.舊.md、問答式.舊.md，要保留的內容記得搬回新版。

移除

  1. 刪掉程式資料夾（上表第一列）。
  2. 工作區裡是你的錄音和會議紀錄，要不要刪自己決定。
  3. 刪掉桌面的「會議紀錄」捷徑。

資料流向

步驟 在哪裡做 會不會離開你的電腦
錄音轉逐字稿 你的電腦（faster-whisper 加上 Breeze 模型） 不會。錄音不上傳
整理成會議紀錄 Claude（Anthropic 的雲端服務） 會。逐字稿、你給的名單、術語和筆記會送到 Claude
產生 Word 你的電腦 不會

安裝時會從網路下載程式套件（PyPI）和語音辨識模型（Hugging Face），只有下載，不會上傳你的資料。

處理客戶或公司的會議之前

整理那一步會把會議內容送到 Claude。客戶會議、公司內部會議能不能這樣處理，要先問過公司或客戶的規定，例如：

  • 能不能用私人電腦處理工作的會議錄音。
  • 能不能用私人的 Claude 帳號處理工作內容。
  • 公司有沒有指定能用的 AI 服務。

錄音存在 OneDrive、iCloud 這類會同步到雲端的資料夾時，錄音也會跟著上傳到那個雲端。工作區預設放在使用者資料夾底下的 會議紀錄，不在「文件」或「桌面」裡，就是為了避開這種同步；指定存到其他位置時，Claude 會先提醒。

常見問題

安裝

雙擊安裝檔後出現「Windows 已保護您的電腦」 按「其他資訊」→「仍要執行」。檔案從網路下載又沒有數位簽章時，Windows 都會這樣擋一次。

Mac 說安裝檔無法打開 見安裝的 Mac 那節，改用終端機執行。

安裝檔說 uv 沒裝成功 多半是網路被擋（例如公司網路）。換個網路再雙擊一次安裝檔。

安裝在某一步失敗了 畫面上會寫是哪一步、最後幾行錯誤訊息，完整記錄在程式資料夾的 logs\install.log。修好之後再雙擊一次安裝檔，已經下載好的模型不會重新下載。

桌面上沒有「會議紀錄」捷徑 英文語系的 Windows 建不了中文名稱的捷徑，安裝檔會跳過這步並提醒。直接到使用者資料夾打開 會議紀錄 就好，也可以自己在檔案總管對它按右鍵「傳送到 → 桌面（建立捷徑）」。

顯示卡驅動太舊 安裝檔會先用 CPU 裝好。到 NVIDIA 官網或電腦廠商的網站更新驅動，再跑一次安裝檔就會改用顯示卡。RTX 50 系列要支援 CUDA 12.8 以上的驅動。

使用

輸入 /會議紀錄 沒反應，或說找不到這個指令 要在工作區（會議紀錄 資料夾）打開 Claude Code 才叫得出來。在別的資料夾打開是找不到的。

一直跳權限詢問 見使用流程的「權限詢問」：選「Yes, and don't ask again」就不會一直問。

支援哪些錄音格式 m4a、wav 實際測過。mp3、flac、ogg、mp4、webm 應該可以，沒有逐一測過。

錄音的時間不對、順序排錯 程式先看檔名裡的時間（例如 語音 YYMMDD_HHMMSS、YYYYMMDD_HHMMSS），沒有再看檔案裡記錄的時間，最後才看檔案修改時間。後兩種會標「時間不確定」，Claude 會請你確認。複製過的檔案，修改時間可能變成複製當下。

人名、專有名詞聽錯 下次在 Claude 問「有沒有名單或專有名詞」時提供，或在會議資料夾放 0_名單與術語.txt，再請 Claude 重轉。名單太長時，後面的會被截掉，Claude 會告訴你哪些沒用上。

轉逐字稿中途關掉了 跟 Claude 說「接著轉逐字稿」就好。錄音已經搬進會議資料夾，做完的段落也存起來了，只會轉沒做完的。

顯示卡轉到一半出錯 程式會自動改用 CPU 重轉那一段，並告訴你原因。

會議紀錄的格式想改 跟 Claude 說要怎麼改就好。要長期改的話，工作區的 .claude\skills\會議紀錄\ 裡有整理規則和格式公版（Windows 上這個資料夾是隱藏的）；重新安裝或更新時，你改過的整理規則會備份成 整理規則.舊.md。
